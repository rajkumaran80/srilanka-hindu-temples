🔧 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════

  Issue: Port 5173 already in use
  Fix:   Edit vite.config.ts → port: 3000 (or another port)

  Issue: Module not found errors
  Fix:   npm install && npm cache clean --force

  Issue: Blank page in browser
  Fix:   Check F12 console → Clear browser cache (Ctrl+Shift+Del)

  Issue: MIME type error still showing
  Fix:   This is OLD cache. Clear browser cache and restart.
